# Chain Notes
A decentralized guestbook where anyone can message on the blockchain.

**Live Demo** 
*work in progress, coming soon*

## Features
-Connect your wallets
-Post and read on-chain messages
-responsive, dark themed UI

## Tech Stack
Solidity, Hardhat, React, ethers.js

## Getting Started
1. Clone the repo: `git clone <repo-url>`
2. Install dependencies: `npm install`
3. Run tests: `npx install`
4. Start the fronted: `cd fronted && npm install && npm run dec`

## What I Learned
- Writing and testing smart contracts
- Connecting a frontend to a wallet
